Data states

Every number on this site comes from a network call that can fail. The live site today renders “rip gps”, “n/a”, an empty mileage chart and an empty activity table — under a SYNCED badge. That is the bug this sheet exists to prevent.

The rule
A module that cannot get its data does not render.
It never shows a placeholder value, a zero it did not measure, a joke, or a “live” label over stale data.
Order of preference when a fetch fails — 1. serve the last good cached value with an honest age label   2. collapse the module and reflow the layout   3. only if it is structural to the page, use the degraded state below.

Banned patterns

“rip gps”, “n/a”, “—” — joke or placeholder values
0 where the value is unknown rather than measured as zero
a live or synced label over cached or seeded data
random or seeded sample data standing in for a real series
an empty chart frame, empty table, or “no data” text block
a raw error message, status code, or stack trace
