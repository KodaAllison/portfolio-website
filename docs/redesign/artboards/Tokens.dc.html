Borders, radius, motion

border width — always 1px. Never 2px except the shelf rule.
radius — 0 everywhere. No rounded corners, no pills, no rounded cards.
grid seams — 1px gap over a #242a2e background, not per-cell borders.
hero line draw — 2400ms cubic-bezier(0.65, 0, 0.35, 1), once
label fade-in — 450ms ease, staggered along the line
globe rotation — 12s linear, infinite (desktop only)
book spine tilt — 280ms cubic-bezier(0.34, 1.4, 0.64, 1)
hover colour — 150ms ease
scroll reveal — 400ms ease, 12px rise, once per section
prefers-reduced-motion: reduce → all of the above become instant final-state. Nothing loops, nothing moves.
